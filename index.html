像写公众号一样写作

677px 纸张版式、绿色主题、拖拽即传。图片与视频走分片上传（可取消、失败自动重试、支持断点续传与秒传），随时切换到 HTML 源码模式查看或改写产物。

零依赖单文件引入

<script src="dist/keditor.umd.js"> + 一行 KEditor.create('#editor')，样式随 JS 注入。

Vue 3 组件

app.use(KEditorVue) 后即可 <k-editor v-model="html" />，支持 disabled 与自定义 options。

分片上传可插拔

内置 mock 适配器开箱即用，一行换成 {type:'http'} 对接真实后端；图片与视频也支持直接粘贴网络链接插入。

源码模式

工具栏常驻「源码」按钮（⌘/Ctrl+Shift+K），格式化、复制、直接编辑并应用，返回可视化时自动净化（白名单标签 + 危险协议拦截）。

自定义工具栏按钮

customButtons 加一个下拉选择按钮：选项可静态配置或从接口读取（带加载/重试/搜索/分组），选中后按模板插入跳转链接或直接打开。
