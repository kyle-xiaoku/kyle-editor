像写公众号一样写作

677px 纸张版式、绿色主题、拖拽即传。图片与视频走上传（小文件整包一次请求、大文件自动切片并发，可取消、失败自动重试、支持断点续传与秒传），代码块可选 20 种语言并语法高亮，支持导入 Markdown 文件/文本转为可编辑 HTML，随时切换到 HTML 源码模式查看或改写产物。

零依赖单文件引入

<script src="dist/keditor.umd.min.js"> + 一行 KEditor.create('#editor')，样式随 JS 注入。

Vue 3 组件

app.use(KEditorVue) 后即可 <k-editor v-model="html" />，支持 disabled 与自定义 options。

上传两条链路，各自配置

内置 mock 适配器开箱即用；对接真实后端：uploader: '/api/upload'（普通上传，整包一次请求）+ chunkUploader: '/api/chunk-upload'（分片上传，响应里 url 非空即成功），小文件与大文件自动选路；图片与视频也支持直接粘贴网络链接插入。

源码模式

工具栏常驻「源码」按钮（⌘/Ctrl+Shift+K），格式化、复制、直接编辑并应用，返回可视化时自动净化（白名单标签 + 危险协议拦截）。

自定义工具栏按钮

customButtons 加一个下拉选择按钮：选项可静态配置或从接口读取（带加载/重试/搜索/分组），选中后按模板插入跳转链接或直接打开；position 决定它站在工具栏的哪个位置（含右侧吸附尾栏）。

代码块选语言 + 高亮

工具栏「代码块」按钮直接展开语言面板（20 种语言，可按 js / mysql 等别名搜索）：块内可边写边高亮，光标在块内时选一项即改写该块语言；导出与源码模式始终是不带高亮标签的干净代码。

高度默认自适应

不写 height 就随内容自动擑开（整页滚动，工具栏尽量吸附视口顶部）；配了才固定高度并在编辑区内部滚动，setHeight() 可运行时切换。

宽屏版心自适应

默认 paperMode: 'fluid'：版心不小于 677px，宽屏时随容器生长，两侧留白恒定 paperGap，不会再出现大屏上一左一右两大块空白。
